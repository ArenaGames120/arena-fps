# Арена FPS — Godot 4

Шутер от первого лица на Godot 4: главное меню, три карты (копии **de_dust2** и
**de_mirage** + тренировочная арена), команды, четыре режима боя, боты с
человекоподобными моделями и хедшотами, три ствола — **АК-47**, **Desert Eagle**
и **снайперская винтовка** (с оптикой), а также уровни и опыт.

## Как запустить

1. Открыть Godot 4 (проект создан под 4.4+, проверялся на 4.7).
2. Нажать **Import / Импорт**, выбрать файл `project.godot` из этой папки.
3. Нажать **Run (F5)** или кнопку ▶ в правом верхнем углу.

## Готовая сборка (exe)

Собранная игра — один самодостаточный файл: `build/ArenaFPS.exe` (двойной клик,
рядом ничего не нужно). Пересобрать после правок можно в редакторе
(`Project → Export… → Windows Desktop`, пресет уже настроен в
`export_presets.cfg`) или из консоли:

```
godot --headless --path . --export-release "Windows Desktop" build/ArenaFPS.exe
```

Для сборки нужны шаблоны экспорта (Editor → Manage Export Templates…).
Иконка игры тоже рисуется кодом, без картинок-ассетов:
`godot --headless --path . --script res://tools/make_icon.gd`.

## Меню

* **ИГРАТЬ** — выбор режима → карты → команды (в FFA команда не нужна, бой
  начинается сразу). Рядом с названием выбранного режима/карты стоит «▶».
* **НАСТРОЙКИ** — чувствительность мыши, угол обзора, громкость, сложность
  ботов, инверсия мыши, полный экран. Всё сохраняется сразу.
* **ВЫХОД ИЗ ИГРЫ**.
* В бою `Esc` — пауза (**ПРОДОЛЖИТЬ**, **НАСТРОЙКИ**, **ГЛАВНОЕ МЕНЮ**,
  **ВЫХОД**). В главном экране меню видна карточка бойца: уровень, звание, опыт,
  статистика убийств/хедшотов/матчей и K/D.

## Режимы боя

| Режим | Формат | Возрождение | Победа |
| --- | --- | --- | --- |
| **Командный бой** (TDM) | 4×4, спецназ против террористов | через 3 с | 50 фрагов команды |
| **Соревновательный** (COMP) | 4×4, раунды по 120 с | нет | 4 выигранных раунда |
| **Напарники** (WINGMAN) | 2×2, раунды по 100 с | нет | 4 выигранных раунда |
| **Каждый сам за себя** (FFA) | 9 бойцов, все против всех | через 3 с | 15 фрагов |

В раундовых режимах перед началом раунда есть подготовка (3 с), после смерти
возрождения нет — раунд играется до зачистки одной из команд; если время
истекло, раунд достаётся спецназу. Своих не задеваем: дружественный огонь в
командных режимах выключен (в FFA он не важен — враги все).

## Карты

* **de_dust2** — две точки (A и B), лонг, мид с дверями, кот, туннели, T и CT спавны.
* **de_mirage** — мид с окном и коннектор, дворец, аппартаменты, кухня, точки A и B.
* **Арена** — тренировочная площадка 68×68 с ящиками и пандусом.

Ориентиры подписаны прямо в мире (`Label3D`): «МИД», «ЛОНГ», «КОТ», «ТУННЕЛИ»,
«ДВОРЕЦ», «A», «B» и т. д. На каждой карте есть точки спавна для обеих команд,
маршруты патрулирования, аптечки и ящики с патронами.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W A S D` | движение |
| `Shift` | бег (тратит выносливость — синяя полоска внизу) |
| `Space` | прыжок |
| `Ctrl` / `C` | присесть (меньше разброс стрельбы) |
| `ЛКМ` | огонь |
| `ПКМ` | прицеливание; у снайперки включается оптика |
| `1` | АК-47 (автоматический, 30 патронов) |
| `2` | Desert Eagle (полуавтомат, 7 патронов, сильная отдача) |
| `3` | Снайперская винтовка (болтовка, 5 патронов, хедшот = мгновенное убийство) |
| `Q` / колесо мыши | сменить оружие |
| `R` | перезарядка |
| `Tab` | табло боя (в командных режимах — по командам, с раундами) |
| `Esc` | пауза, освобождает курсор |

## Опыт и уровни

* Опыт даётся за фраг (10–15), хедшот (15–20), выигранный раунд (40–50),
  проигранный раунд (15–20) и за исход матча (50–220). Точные числа — в
  `scripts/Modes.gd`.
* Опыт до нового уровня: `150 + 100 × (уровень − 1)`. За уровень — новое звание
  (Новочок → … → Легенда). В бою слева сверху видна полоса опыта, за фраг
  всплывает «+N ОПЫТ», за уровень — баннер по центру.
* Прогресс и настройки сохраняются в `user://save.cfg` (папка данных Godot) и
  подхватываются при следующем запуске.

## Что есть в игре

* Боты с ИИ на человекоподобных моделях: патрулируют, замечают врага (и игрока,
  и других ботов), держат дистанцию, стреляют очередями, обходят препятствия,
  прыгают через укрытия, помнят, откуда в них стреляли, и добивают последних
  выживших на вражеском респауне.
* Хедшот-зона у каждого бойца (сфера на голове): хедшот даёт повышенный урон,
  у снайперки — мгновенное убийство.
* Три ствола с разными характеристиками, разбросом, отдачей и перезарядкой.
* Здоровье, выносливость, броня жилета визуально, килл-фид, табло фрагов,
  счёт команд, таймер и номер раунда, баннеры «РАУНД ВЫИГРАН», экран смерти с
  именем убийцы, финал матча с итоговой таблицей и начисленным опытом.
* Подбираемые аптечки (зелёные) и ящики с патронами (жёлтые) — возрождаются сами.
* Все звуки синтезируются кодом в `scripts/Sfx.gd` — внешних ассетов нет.

## Структура проекта

```
project.godot          настройки, слои физики, стартовая сцена
scenes/Main.tscn       корневая сцена (весь мир собирается кодом)
scripts/Main.gd        матч: меню, карты, команды, раунды, фраги, опыт
scripts/Menu.gd        главное меню: играть/настройки/выход, выбор режима и карты
scripts/HUD.gd         прицел, полоски, счёт матча, табло, пауза, финал, оптика
scripts/Player.gd      игрок: движение, оружие, стрельба, урон
scripts/Bot.gd         ИИ бойца: команда, выбор цели, зрение, стрельба
scripts/Human.gd       человекоподобная модель бойца (собирается кодом)
scripts/Levels.gd      карты de_dust2, de_mirage и арена
scripts/Modes.gd       режимы боя: форматы, правила и награды опытом
scripts/Progression.gd уровни, звания, опыт, статистика и настройки (save.cfg)
scripts/Weapons.gd     характеристики АК-47, Desert Eagle и снайперки
scripts/Effects.gd     трассеры, вспышки выстрела, искры и кровь
scripts/Sfx.gd         синтез звуков (выстрелы, перезарядка, шаги)
scripts/Pickup.gd      аптечки и патроны
scripts/GameInput.gd   регистрация клавиш в рантайме
```

## Быстрая настройка под себя

* Оружие: `scripts/Weapons.gd` — урон, скорострельность, магазин, разброс, отдача.
* Режимы: `scripts/Modes.gd` — формат, раунды, лимиты фрагов и награды опытом.
* Карты: `scripts/Levels.gd` — размеры, стены, спавны, маршруты и подписи;
  в `MAPS` у каждой карты указаны `half` (половина карты), `desc` и список точек.
* Боты: `Bot.set_difficulty()` в `scripts/Bot.gd` — реакция, точность, урон,
  скорость; `PLAYER_TARGET_BIAS` — насколько охотно боты выбирают целью игрока.
* Матч: константы в начале `scripts/Main.gd` — `RESPAWN_DELAY`, `FREEZE_TIME`,
  `ROUND_BREAK`, цвета команд и бойцов.
* Уровни: `scripts/Progression.gd` — `xp_to_next()`, названия званий, статистика.
